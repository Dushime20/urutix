## 🎯 **How to Integrate**

### **Quick Integration (15 minutes)**

1. **Install Dependencies**
   ```bash
   cd frontend
   npm install leaflet react-leaflet recharts @types/leaflet
   ```

2. **Add Leaflet CSS** (frontend/index.html)
   ```html
   <link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
   ```

3. **Add to Dashboard** (frontend/src/pages/Dashboard.tsx)
   ```typescript
   // Import components
   import VoiceCargoInput from '../components/VoiceInput/VoiceCargoInput';
   import CameraDocumentScanner from '../components/Camera/CameraDocumentScanner';
   
   // Add state
   const [showVoiceInput, setShowVoiceInput] = useState(false);
   const [showDocumentScanner, setShowDocumentScanner] = useState(false);
   
   // Add buttons to dashboard
   <button onClick={() => setShowVoiceInput(true)}>
     Voice Input
   </button>
   
   // Add modals
   {showVoiceInput && <VoiceCargoInput ... />}
   {showDocumentScanner && <CameraDocumentScanner ... />}
   ```

4. **Test Features**
   - Open Dashboard
   - Click "Voice Input" - should open voice modal
   - Click "Scan Document" - should open camera modal
   - Click "Route Planner" - should show map

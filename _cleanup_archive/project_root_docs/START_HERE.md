## 🚨 **Important Notes**

### **Prerequisites**
- Node.js 18+
- PostgreSQL 14+
- Redis
- HTTPS for voice & camera
- Modern browser (Chrome/Edge/Safari/Firefox)

### **Browser Compatibility**
- ✅ Voice Input: Chrome 90+, Edge 90+
- ✅ Camera Scanner: All modern browsers (HTTPS)
- ✅ Geolocation: All modern browsers
- ✅ PWA: Chrome, Edge, Safari 14+

### **Security**
- All features require HTTPS in production
- User consent required for camera/microphone
- Data encrypted in transit and at rest
- Role-based access control
- Rate limiting enabled

  - `RURAL_LOCATION` (instead of generic "RURAL")
  - `GENERAL_FACILITY` (instead of generic "GENERAL")

- **Access Types**:
  - `INDUSTRIAL_TRUCK_ACCESS` (for industrial areas)
  - `URBAN_TRUCK_ACCESS` (for urban areas)
  - `RURAL_TRUCK_ACCESS` (for rural areas)

- **Security Levels**:
  - `INDUSTRIAL_SECURITY` (for industrial facilities)
  - `URBAN_SECURITY` (for urban locations)
  - `RURAL_SECURITY` (for rural locations)
  - `PUBLIC_ACCESS` (for public facilities)

- **Sub-Categories**:
  - `CARGO_PICKUP_FACILITY` (instead of "PICKUP_POINT")
  - `CARGO_DELIVERY_FACILITY` (instead of "DELIVERY_POINT")
  - `TRANSIT_STOP_POINT` (instead of "STOP_POINT")

# 🚀 AI Email Assistant - START HERE

## ⚡ 3-Step Setup (5 minutes)

### 1️⃣ Get Free API Key
Visit: **https://makersuite.google.com/app/apikey**
- Sign in with Google
- Click "Create API Key"
- Copy the key

### 2️⃣ Add to Backend
Edit `backend/.env`:
```env
GEMINI_API_KEY=AIzaSyC...paste-your-key-here
```

### 3️⃣ Restart & Test
```bash
cd backend
node test-gemini-ai.js    # Optional: Test AI
npm run start:dev         # Start backend
```

Look for: `✅ AI Email Assistant initialized with Google Gemini`
